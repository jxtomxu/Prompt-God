# Prompt God

**把普通问题升级为真正能推动结果的高杠杆 Prompt。**

Prompt God 是一个可复用的 ChatGPT / Agent Skill。围绕 **Speed、Altitude、Depth、Range** 四个维度优化任务设计：明确最终结果、找到一手资料、引入专家实际使用的方法、补充跨学科验证，并让交付结果可检验。

> **调用 Prompt God 时，默认只输出优化后的提示词，不直接执行任务。** 只有明确要求“优化后再执行”，才执行后续任务。

## 使用示例

```text
@Prompt God 调研美国 graded card storage case 用户真实痛点，寻找差异化产品方向。
```

## 核心方法

- **Altitude · 升维**：明确任务背后的真正结果。
- **Depth · 钻深**：使用一手证据与专业方法。
- **Range · 扩域**：借鉴有实际增益的跨学科方法。
- **Speed · 提速**：减少重复操作，不牺牲验证。

## 安装

将本仓库作为 ChatGPT / Agent Skill 导入，入口文件为根目录 `SKILL.md`。
